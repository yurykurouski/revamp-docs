# История мозгового штурма: Проект Revamp

Этот документ содержит хронологию и ключевые решения, принятые в ходе нашего обсуждения концепции и архитектуры SaaS-платформы.

## 1. Идея и бизнес-логика
Мы начали с концепции SaaS-инструмента, который автоматизирует аудит сайтов локальных бизнесов, генерирует уникальные демо-версии (MVP) с сохранением оригинального брендового стиля и управляет рассылкой предложений. Основной упор сделан на "человечный", персонализированный подход к email-outreach с обязательной ручной модерацией перед отправкой, чтобы избежать ощущения шаблонного спама.

## 2. Выбор технологического стека
* Frontend: React в связке с Material UI. Выбран для максимально быстрого и простого построения интерфейса панели управления. Детализацию интерфейса отложили на будущее.
* Backend: Node.js + Express. Выбран за счет простоты настройки и возможности использовать JavaScript на всех уровнях приложения.
* База данных: MongoDB. Выбрана как наиболее гибкая и подходящая NoSQL база для управления данными клиентов.

## 3. Архитектура данных (Модель клиента)
Определили базовый набор данных для отображения статуса клиентов в дашборде:
* Название клиента и сайт
* Контактный email
* Дата проведения проверки
* Статус оценки (assessment)
* Статус готовности MVP
* Статистика отправленных сообщений

## 4. Логика работы бэкенда и агентов
Аудирующий агент получает информацию о клиенте из базы данных, выполняет анализ сайта и записывает результаты (оценки, выявленные недостатки) обратно в MongoDB. После этого обновленные данные мгновенно подтягиваются на дашборд для рассмотрения.

## 5. Выбор названия проекта
Были рассмотрены различные подходы к неймингу: от функциональных (AuditGen, SiteRevive) до более абстрактных (Uplift, Bloom, Pulse). Вы остановили свой выбор на Revamp. Проверку доступности домена решили пока не проводить.

## 6. Текущий этап и следующие шаги
Был сформирован детализированный blueprint проекта для передачи в другие LLM-модели. Следующим шагом в рамках реализации будет разработка структуры проекта для React-дашборда.
